Citerra is an academic research and writing environment that brings together a document editor, reference library, citation management, PDF tools, and a source-grounded AI assistant. Everything lives in one workspace, allowing research and writing to progress without constant tool-switching or loss of context.

## Features

Citerra supports the entire research-writing process, from discovering the first source to exporting the final document.

- **Write:** Choose between LaTeX and WYSIWYG editing workflows. Use an academic AI assistant grounded in the active document and its linked sources. Export finished work as PDF, Word, or LaTeX.
- **Research:** Search major academic databases and use an integrated PDF workspace to read, annotate, summarize, extract references, and ask questions about papers.
- **Cite:** Organize sources, notes, and metadata in a structured, searchable library. Insert and track citations while automatically generating accurately formatted bibliographies.
- **Verify:** Run similarity checks to identify potentially overlapping text before submission.

## The Citerra Platform

These features are built on a small set of architectural principles that define how Citerra works.

- **Modular core:** Writing, citations, library management, literature search, PDF tools, and similarity checking operate as independent, composable services.
- **Context-scoped AI:** The assistant works only with the active document and its linked sources. Its responses remain grounded in the user’s research context rather than introducing unsupported information.
- **Document-centered workspace:** Each document maintains its own structure, references, metadata, and AI context instead of relying on a separate, general-purpose chat.
- **Real-time synchronization:** Documents, versions, and metadata remain consistent across devices.
- **Citerra Cloud:** Documents, sources, and metadata are stored and managed in a unified cloud environment rather than scattered across local files.
